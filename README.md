# 이규재의 게임 디자인 포트폴리오

**[웹사이트 바로 보기](https://l-egulation.github.io/portfolio/)** · [슬라이드형 보기](https://l-egulation.github.io/portfolio/slide-html/index.html)

맥 스타일 작업실을 모티브로 만든 정적 웹 포트폴리오입니다.

- 메인: `index.html`
- 슬라이드형 보기: `slide-html/index.html`
- 프로젝트: 한짝, Cam, On!, deviant(개발 중), Pickle, AI 챌린지

HTML, CSS, JavaScript와 `assets/` 이미지를 함께 사용하는 구조입니다. 빌드, 별도 서버 프로그램, 데이터베이스 없이 정적 호스팅에서 실행할 수 있습니다. GitHub Pages는 기본 브랜치의 루트 폴더를 게시 대상으로 사용하면 됩니다. Netlify에서도 저장소 루트를 게시할 수 있습니다.

로컬에서는 `index.html`을 브라우저로 열 수 있습니다. 파일을 옮길 때는 이미지와 CSS/JavaScript를 함께 유지하세요. ZIP은 전달용이며 웹사이트 실행에 필요하지 않습니다.

화면 자료는 실제 프로젝트 Figma 시안과 발표 자료입니다. 개인 역할·팀 작업·설계 목표·구현 상태는 각 사례에서 구분했습니다. 원본 경험 문서, DB, 개인 계정 단위 데이터는 포함하지 않았습니다.
